# AI 辅助过程与记录索引

本目录提供 [任务摘要](task-brief.md) 和 [过程摘要](../docs/process.md)，配合 evidence 中的真实工具结果，展示选题约束、实现、问题修正与验证。

当前聊天已从本地 Hermes 会话数据库导出至受 Git 忽略保护的审阅目录，不再需要用户手动寻找或复制聊天。公开版尚未纳入本目录，需完成隐私与覆盖范围核查；现有摘要不冒充完整逐字记录。详情见 [交付范围与证据说明](../docs/missing-materials.md)。

原始导出应先放在仓库外，或被忽略的 `private-local/` / `raw-ai-exports/` 内审阅，不直接发布密码、Token、认证信息、本机账户及无关服务器资料。无需读取任何凭据文件来完成归档。
