# 智能体交互记录

本目录已加入当前作业会话的真实消息公开副本，按阶段保留学生指令、助手回复、工具调用与工具结果，不再只有任务摘要。共 311 条现存记录，覆盖工程检查、开发、验证修正、部署指导与课程仓库整理。

## 建议评阅顺序

1. [环境检查、任务确认与实现](transcripts/01-environment-and-development.md)：从只读检查到 Structured Outputs 开发任务。
2. [中断恢复、验证与修正](transcripts/02-verification-and-fixes.md)：恢复工作、浏览器验收、问题修正和预览停止。
3. [部署指导与用户回传](transcripts/03-deployment-guidance.md)：真实终端反馈，区分助手提供指令与用户实际执行。
4. [课程仓库整理、学习笔记与 Git 排查](transcripts/04-coursework-archive.md)：交付范围确认、独立仓库归档和提交前检查。

快速了解过程可先读 [任务摘要](task-brief.md) 与 [过程摘要](../docs/process.md)；它们明确是摘要，不替代上述消息记录。

## 数据与覆盖说明

- [机器可读消息记录](interaction-records.jsonl)：与四个章节相同的 311 条记录。
- [导出清单与 SHA-256](export-manifest.json)：条数、排除编号、脱敏类别及文件校验值。
- [来源、范围与公开处理说明](export-notes.md)：必读。范围截至数据库消息 409；后续导出维护不包含在快照中。排除内部技能/工具定义及运行时摘要，保留原记录中的失败、纠正、重放和截断。

原数据库未改动。公开副本已替换非必要环境标识并完成敏感模式检查；不包括系统提示、内部推理或认证材料。不声称数据库保留了每一条原始消息，也不以摘要补造缺口。

原始导出应先放在仓库外，或被忽略的 `private-local/` / `raw-ai-exports/` 内审阅，不直接发布密码、Token、认证信息、本机账户及无关服务器资料。无需读取任何凭据文件来完成归档。
