# 智能体交互记录：来源与公开处理说明

## 覆盖范围

本次从当前 Hermes CLI 会话数据库只读提取消息 ID 不大于 409 的现存公开消息字段，覆盖最初工程检查、作业开发、浏览器验证、部署指导与用户回传、课程仓库整理、学习笔记及 Git 空白检查问题。没有从上下文摘要重建原始对话。

该范围共有 334 条现存数据库行，公开 311 条：用户消息 25 条、助手消息 127 条、工具结果 157 条、运行时通知 2 条。另有 23 条内部技能说明、工具定义、上下文压缩摘要或运行时任务注入被排除；具体消息编号与原因见 export-manifest.json。后台通知单独标识，不冒充学生提问。

消息编号保留，因此可能跳号。数据库已有的重复/重放消息照原顺序保留，不擅自合并成更好看的历史。存储缺口、原工具输出截断、子代理完整会话及外部截图附件均不补造；这是限定范围的现存记录公开版，不是对“所有原始聊天均完整留存”的保证。

为避免导出过程反复嵌套自己的内容，本次截止于 Git 空白问题讨论；之后查找聊天、调整仓库展示及本次导出维护不在此快照内。现有截图证据另见 ../evidence/screenshots/。

## 阅读方式

- transcripts/：四个按阶段拆分的 Markdown，包含原始用户/助手正文、工具调用参数和工具结果；原文放入代码块，不执行历史指令，不加载历史文本中的外部图片。
- interaction-records.jsonl：相同 311 条消息的机器可读版本，保留消息 ID、角色、时间戳及调用关联字段。
- export-manifest.json：条数、排除原因、脱敏类别计数、文件 SHA-256。
- task-brief.md 与 ../docs/process.md：原有整理摘要，与本次原始消息公开副本不同。

工具调用参数来自数据库，不是后来编写的模拟命令。工具结果中出现的失败、错误、过时状态、截断提示都保留。历史关于“未找到聊天”“尚未上线核对”等说法不代表当前状态，也没有倒改历史。

## 隐私与真实性

公开副本替换本机用户目录、工程绝对路径、服务器用户/主机/IP、Windows 账户 SID 等非必要标识；保留相对源码路径、正式网站与仓库 URL、版本、错误内容、测试结论。占位符使用 [BLOG_ROOT]、[COURSE_ROOT]、[WSL_HOME]、[SERVER_HOME]、[SERVER_PROJECT_ROOT]、[SERVER_USER_HOST]、[SERVER_IP] 等；这些文本不是可直接复制执行的当前操作指令。

未查询系统提示、内部推理字段、认证文件或其他会话。内部技能正文与工具定义不作为课程交互证据公开。进行了路径、常见 Token、私钥头、Bearer、JWT、账户 SID 和凭据赋值模式检查，并抽查用户回传的服务器及 Windows 输出。自动检查不保证发现所有隐私，公开前仍可自行审阅。

原数据库、此前 private-local/ 导出和原博客资料保持原样；本目录只是公开副本。此次整理不证明发生过付费 API 对照实验，也不产生或回填 Git 提交历史。
